1. First spells 🪄

What JavaScript does

HTML supplies structure, CSS supplies appearance, and JavaScript adds behavior. JavaScript can react to events, change the page, calculate values, and communicate with services. In these examples, print() is a helper supplied by this guide; console.log() is the usual way to log to browser developer tools.

JAVASCRIPT
print('Welcome to Dragon Academy!');
console.log('Also visible in developer tools.');

Where to write JavaScript

Place JavaScript inside a script element or load a separate .js file. defer on an external classic script lets HTML parsing finish before execution. This code is an HTML setup example; it is not run here.

Statements and comments

Statements tell the program what to do. // starts a single-line comment; /* ... */ encloses a block comment. Strings need quotes; JavaScript is case-sensitive.

JAVASCRIPT
// Announce the lesson.
print('Flying starts at 9 AM.');
/* Comments are ignored by the program. */

let, const, and var

let declares a variable you may reassign. const requires an initial value and prevents reassignment of that binding. Both are block-scoped. Older var is function-scoped and behaves differently; prefer const by default and let when reassignment is needed.

JAVASCRIPT
const dragon = 'Chilli';
let points = 10;
points += 5;
print(dragon + ': ' + points + ' points');
LIVE RESULT

const does not freeze an object or array: their contents can still change.

2. Values and calculations 🧮

Data types

Common primitives are string, number, boolean, undefined, null, bigint, and symbol. Objects include arrays and functions. typeof helps inspect types, but typeof null is the historical exception "object".

JAVASCRIPT
print(typeof 'Chilli');
print(typeof 42);
print(typeof true);
let unknown;
print(typeof unknown);
print(typeof null);
print(typeof 10n);
print(typeof Symbol('id'));
print(Array.isArray(['Fire', 'Ice']));
LIVE RESULT

Arithmetic and assignment

+ adds numbers (or concatenates strings), - subtracts, * multiplies, / divides, % gives the remainder, and ** raises a power. += updates a value. Parentheses control grouping.

JAVASCRIPT
let coins = 20;
coins += 5;
print(coins);
print(10 % 3);
print(2 ** 3);
print((4 + 2) * 3);
LIVE RESULT

Comparisons and logical operators

=== compares without type coercion; !== checks strict inequality. >, <, >=, and <= compare values. && and || short-circuit and return operand values, not always booleans. ! negates truthiness.

JAVASCRIPT
print(5 === '5');
print(5 == '5'); // Coercion: true
const age = 18;
const hasHelmet = true;
print(age >= 16 && hasHelmet);
print(!hasHelmet);
LIVE RESULT

Prefer strict equality unless you deliberately want coercion.

Conversion, truthiness, and nullish defaults

Number(), String(), and Boolean() convert values. Falsy values include false, 0, empty string, null, undefined, and NaN. Empty arrays and objects are truthy. ?? supplies a default only for null or undefined; || also replaces other falsy values.

JAVASCRIPT
print(Number('25') + 5);
print(Boolean('false')); // Nonempty string: true
print(Boolean([]));
print(0 || 10);
print(0 ?? 10);
print(Number.isNaN(Number('dragon')));
LIVE RESULT

Strings and template literals

Strings store text. Template literals use backticks and ${...} to insert expressions. String methods return new strings; strings are immutable.

JAVASCRIPT
const name = 'Chilli';
print(`Hello, ${name}!`);
print(name.toUpperCase());
print('  Fire  '.trim());
print('Dragon Academy'.includes('Academy'));
print(name.slice(0, 3));
LIVE RESULT

Numbers, Math, and Date

Math provides numeric helpers; Date represents a date-time. Math.random() is useful for casual game examples, not security tokens. Date month indexes in the numeric constructor start at zero.

JAVASCRIPT
print(Math.round(4.7));
print(Math.max(10, 25, 8));
print(Math.floor(Math.random() * 6) + 1);
const lesson = new Date(2026, 8, 13);
print(lesson.toLocaleDateString());
print((0.1 + 0.2).toFixed(2));
LIVE RESULT

Floating-point arithmetic can have tiny rounding differences. toFixed() returns a string.

3. Make decisions and repeat 🔁

if, else if, and else

Run a branch only when its condition is truthy. The first matching branch wins.

JAVASCRIPT
const score = 75;
if (score >= 90) {
  print('Master trainer');
} else if (score >= 60) {
  print('Ready to fly');
} else {
  print('More practice needed');
}
LIVE RESULT

Ternary and switch

The ternary operator condition ? a : b chooses one expression. switch compares cases using strict equality. break exits a case; without it, execution can fall through.

JAVASCRIPT
const hasHelmet = true;
print(hasHelmet ? 'Board the dragon' : 'Get a helmet');
const element = 'ice';
switch (element) {
  case 'fire': print('Bring water'); break;
  case 'ice': print('Bring a coat'); break;
  default: print('Bring a shield');
}
LIVE RESULT

for, while, and do...while

for combines initialization, condition, and update. while checks before every iteration. do...while runs the body at least once. Always ensure loops can end.

JAVASCRIPT
for (let lap = 1; lap <= 3; lap++) {
  print('Flying lap ' + lap);
}
let energy = 2;
while (energy > 0) {
  print('Energy: ' + energy);
  energy--;
}
do { print('At least one greeting!'); } while (false);
LIVE RESULT

for...of, for...in, break, and continue

for...of iterates values in an iterable such as an array. for...in iterates enumerable string keys, including inherited ones; Object.keys() is often clearer for an object’s own keys. continue skips an iteration; break ends the loop.

JAVASCRIPT
for (const skill of ['Flying', 'Sleeping', 'Healing']) {
  if (skill === 'Sleeping') continue;
  print(skill);
}
const stats = { speed: 80, power: 90 };
for (const key of Object.keys(stats)) {
  print(key + ': ' + stats[key]);
}
for (let n = 1; n <= 5; n++) {
  if (n === 3) break;
  print(n);
}
LIVE RESULT

4. Reusable spells: functions 🧙

Functions, parameters, and return

A function packages reusable behavior. Parameters receive arguments. return sends a value back and ends that call. Without an explicit returned value, the result is undefined.

JAVASCRIPT
function feedDragon(name, portions = 1) {
  return name + ' ate ' + portions + ' portions.';
}
print(feedDragon('Chilli', 3));
print(feedDragon('Frosty'));
LIVE RESULT

Arrow functions and callbacks

Arrow functions offer compact syntax. A callback is a function passed to another function. Arrows capture the surrounding this; they do not create their own this binding.

JAVASCRIPT
const double = number => number * 2;
function reward(points, transform) {
  return transform(points);
}
print(reward(10, double));
print([1, 2, 3].map(n => n * 3));
LIVE RESULT

Scope, hoisting, and closures

Scope controls where a name is accessible. A closure lets a function retain access to its surrounding lexical variables. Function declarations can generally be called earlier in their scope; accessing let or const before initialization throws an error.

JAVASCRIPT
function createCounter() {
  let count = 0;
  return function () {
    count++;
    return count;
  };
}
const countFlights = createCounter();
print(countFlights());
print(countFlights());
LIVE RESULT

Each call to createCounter() creates independent counter state.

5. Inventory and dragon profiles 🎒

Arrays and basic methods

Arrays store ordered values with zero-based indexes. push/pop add/remove at the end; unshift/shift work at the start. includes checks membership; slice copies a portion; splice changes the array.

JAVASCRIPT
const bag = ['Helmet', 'Shield'];
bag.push('Snacks');
print(bag[0]);
print(bag.length);
print(bag.includes('Shield'));
print(bag.slice(0, 2));
print(bag.pop());
print(bag);
LIVE RESULT

map, filter, find, and reduce

map transforms each item into a new array. filter keeps matching items. find returns the first match or undefined. reduce combines items into a result.

JAVASCRIPT
const points = [20, 50, 80];
print(points.map(n => n + 10));
print(points.filter(n => n >= 50));
print(points.find(n => n > 40));
print(points.reduce((total, n) => total + n, 0));
LIVE RESULT

Sorting and mutation

sort() mutates its array and defaults to string-based ordering. Supply a numeric comparator for numbers. Copy first when the original order should stay unchanged.

JAVASCRIPT
const scores = [80, 5, 100];
const ranked = [...scores].sort((a, b) => b - a);
print(ranked);
print(scores);
LIVE RESULT

Objects, properties, and methods

Objects group named properties. Use dot notation for a known key and brackets for a dynamic key. A method is a function property. In this direct method call, this refers to the dragon object.

JAVASCRIPT
const dragon = {
  name: 'Chilli',
  power: 90,
  roar() { return this.name + ' says ROAR!'; }
};
const key = 'power';
print(dragon.name);
print(dragon[key]);
print(dragon.roar());
print(Object.keys(dragon));
LIVE RESULT

Destructuring, spread, rest, and optional chaining

Destructuring extracts values. Spread expands an array or copies properties. Rest collects remaining values. ?. safely stops when the value before it is null or undefined.

JAVASCRIPT
const dragon = { name: 'Chilli', power: 90 };
const { name, power } = dragon;
const upgraded = { ...dragon, power: power + 10 };
const [first, ...others] = ['Fire', 'Ice', 'Storm'];
print(name);
print(upgraded);
print(others);
print(dragon.owner?.name ?? 'No owner yet');
LIVE RESULT

Spread makes a shallow copy; nested objects can still be shared.

Classes and instances

A class is syntax for constructing objects with shared prototype methods. constructor initializes an instance. new creates an instance. extends and super support inheritance when that relationship is useful.

JAVASCRIPT
class Dragon {
  constructor(name) { this.name = name; }
  fly() { return this.name + ' takes flight!'; }
}
const chilli = new Dragon('Chilli');
print(chilli.fly());
LIVE RESULT

JSON

JSON is a text data format. JSON.stringify() serializes compatible data; JSON.parse() reads it back. JSON uses double-quoted keys and strings and cannot represent functions, undefined, or BigInt directly.

JAVASCRIPT
const saved = JSON.stringify({ dragon: 'Chilli', level: 3 });
print(saved);
const restored = JSON.parse(saved);
print(restored.dragon);

6. Bring the page to life ⚡

DOM selection and text updates

The DOM is the browser’s object representation of HTML. querySelector finds the first match; querySelectorAll returns a static collection of matches. textContent updates plain text safely.

HTML
<p id="message">Waiting for a dragon…</p>
JAVASCRIPT
const message = document.querySelector('#message');
message.textContent = 'Chilli is ready to fly!';
message.classList.add('ready');
print(document.querySelectorAll('p').length);
LIVE RESULT

Use textContent for untrusted text. innerHTML parses markup and must not receive unsanitized untrusted content.

Create, append, remove, and classList

createElement makes an element. append inserts it. remove deletes it from the DOM. classList adds, removes, or toggles CSS classes without replacing every class.

HTML
<ul id="inventory"><li>Shield</li></ul>
JAVASCRIPT
const list = document.querySelector('#inventory');
const item = document.createElement('li');
item.textContent = 'Fireproof helmet';
list.append(item);
item.classList.add('ready');
print('Inventory updated.');
LIVE RESULT

Events and addEventListener

An event listener reacts to an action. The callback runs when the event occurs, not when it is registered. Run the example, then press the button.

HTML
<button id="fly">Fly 🐉</button><p id="flights">Flights: 0</p>
JAVASCRIPT
let flights = 0;
document.querySelector('#fly').addEventListener('click', () => {
  flights++;
  document.querySelector('#flights').textContent = 'Flights: ' + flights;
});
LIVE RESULT

Event bubbling and delegation

Many events bubble from their target through ancestors. Delegation attaches one listener to a parent and checks which child was activated. currentTarget is the listener’s element; target is where the event originated.

HTML
<div id="skills"><button data-skill="Flying selected">Flying</button> <button data-skill="Healing selected">Healing</button></div><p id="chosen">Choose a skill.</p>
JAVASCRIPT
document.querySelector('#skills').addEventListener('click', event => {
  const button = event.target.closest('button');
  if (!button) return;
  document.querySelector('#chosen').textContent = button.dataset.skill;
});
LIVE RESULT

Forms, input, and preventDefault

Input values usually arrive as strings. Convert them explicitly when calculating. preventDefault stops the form’s normal navigation/submission. Browser validation helps users; a real server must also validate submissions.

HTML
<form><label>Trainer name <input id="trainer" required></label> <button>Join academy</button></form><p id="greeting"></p>
JAVASCRIPT
document.querySelector('form').addEventListener('submit', event => {
  event.preventDefault();
  const name = document.querySelector('#trainer').value.trim();
  document.querySelector('#greeting').textContent = 'Welcome, ' + name + '!';
});
LIVE RESULT

Live input and numeric values

The input event fires as a control’s value changes. valueAsNumber reads numeric input as a number and may return NaN for invalid or empty values.

HTML
<label>Volume <input id="volume" type="range" min="0" max="100" value="50"></label><p id="level">Roar volume: 50</p>
JAVASCRIPT
const range = document.querySelector('#volume');
const label = document.querySelector('#level');
range.addEventListener('input', () => {
  label.textContent = 'Roar volume: ' + range.valueAsNumber;
});
LIVE RESULT

7. Wait without freezing the academy ⏳

Timers and the event loop

setTimeout schedules a callback after at least the specified delay; it does not pause the current script. Its timing is not exact. setInterval repeats callbacks; clearTimeout and clearInterval cancel scheduled work.

JAVASCRIPT
print('1. Start training');
setTimeout(() => print('3. Dragon landed!'), 700);
print('2. Continue other work');
LIVE RESULT

Promises

A Promise represents eventual fulfillment or rejection. then handles success, catch handles rejection, and finally runs after settlement. This example simulates a short wait without a network request.

JAVASCRIPT
const lesson = new Promise(resolve => {
  setTimeout(() => resolve('Flying badge unlocked!'), 500);
});
lesson.then(message => print(message));
print('Waiting for the lesson…');
LIVE RESULT

async, await, and try/catch

An async function returns a Promise. await pauses that function until the value settles; it does not block the whole page. try/catch handles thrown errors and awaited rejections.

JAVASCRIPT
async function train() {
  try {
    const badge = await Promise.resolve('Fire safety badge');
    print(badge);
  } catch (error) {
    print(error.message);
  } finally {
    print('Lesson finished.');
  }
}
train();
LIVE RESULT

fetch and HTTP errors

fetch requests a resource and returns a Promise. HTTP error responses such as 404 do not automatically reject: check response.ok. Reading JSON is asynchronous too. This is a reference example; it needs a real endpoint and is not run offline.

REFERENCE CODE
async function loadDragons() {
  try {
    const response = await fetch('/api/dragons');
    if (!response.ok) throw new Error('HTTP ' + response.status);
    const dragons = await response.json();
    console.log(dragons);
  } catch (error) {
    console.error('Could not load dragons:', error.message);
  }
}
loadDragons();

Cross-origin requests depend on the server’s CORS policy. Never put private API keys in browser JavaScript.

8. Save, organize, and debug 🧰

localStorage and sessionStorage

Both store strings by origin. localStorage normally persists between sessions; sessionStorage is tied to a tab’s session. Serialize objects with JSON. Storage may be unavailable or full; local-file behavior varies, so this example is reference-only.

REFERENCE CODE
try {
  localStorage.setItem('dragon', JSON.stringify({ name: 'Chilli' }));
  const raw = localStorage.getItem('dragon');
  const dragon = raw ? JSON.parse(raw) : null;
  console.log(dragon?.name);
  localStorage.removeItem('dragon');
} catch (error) {
  console.error('Storage unavailable:', error.message);
}

Do not treat browser storage as secure storage for passwords or sensitive secrets.

Modules: export and import

Modules split code into reusable files and run in strict mode. Load browser modules with type="module". Serve module examples over a local HTTP server rather than relying on file:// behavior.

REFERENCE CODE
// dragon.js
export function roar() { return 'ROAAAR!'; }

// app.js
import { roar } from './dragon.js';
console.log(roar());

// HTML:
// <script type="module" src="app.js"></script>

Errors and debugging

Syntax errors prevent parsing. Reference errors often mean an unknown variable. Type errors often mean an operation is invalid for a value. Use developer tools, console.log(), breakpoints, and the call stack to inspect behavior.

JAVASCRIPT
try {
  const dragon = null;
  print(dragon.name);
} catch (error) {
  print(error.name);
  print('Caught the mistake; the program can continue.');
}
LIVE RESULT

Regular expressions

A regular expression describes a text pattern. test() checks for a match; replace() can substitute matches. Flags such as i ignore case and g match globally.

JAVASCRIPT
const dragonName = 'Chilli42';
print(/^[a-z]+\d*$/i.test(dragonName));
print('fire fire ice'.replace(/fire/g, '🔥'));
LIVE RESULT

Simple patterns are useful, but do not invent a tiny regex and assume it validates every real email address.
